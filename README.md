# OnlyWrite · 只写不删

一个**写下去就收不回来**的写作应用。

字一上屏就是刻死的，退格、删除、剪切、撤销全部无效。想改，只能「划掉」——原文保留，只加一道红线。

---

## 两个版本

| | 标准版 | Delta 版 |
|---|---|---|
| 包名 | `com.greed.onlywrite` | `com.greed.onlywrite.delta` |
| 应用名 | OnlyWrite | OnlyWrite Delta |
| 图标 | ONLYWRITE 字标 | 另一套 |
| 提示方式 | 系统 Toast（弹出即消失） | **底栏常驻提示区**（一直挂着，可回看） |

除提示方式外，功能完全一致。两个可以同时安装。

---

## 核心规则

1. **只能写入，不能删除。** 退格、删除、剪切、撤销都在输入层被拦死，字符进不了缓冲区。
2. **只可以替换。** 选中后「划掉」，原文变灰加红线，但仍留在文中。
3. **换行即封存。** 回车会刻下一条时间戳，这一段从此只读。
4. **全都留着。** 每一笔操作都进 SQLite，带 SHA-256 链；数据库层面用触发器禁止 UPDATE / DELETE。

---

## 主要功能

- **刻录** — 正文编辑，回车自动打时间戳并缩进两格
- **划掉** — 选中文字点「划掉」，灰字 + 红线
- **时间行显隐** — 顶栏 `▪时间`，隐藏后不占版面，链不受影响
- **归档** — 封存当前卷、另起新卷；归档以时间戳命名
- **注记** — 归档页可选中文字加批注，同一段可多次注记，按时间分四档渐色
- **拾音** — 边写边录，开始刻「寄耳」、结束刻「还心」，音频落 `Music/OnlyWrite/`
- **导出** — 侧栏底部可把全部归档导出为 TXT + 完整链 JSON
- **字体** — 支持导入自己的 TTF/OTF，全局生效

## 安装

1. 下载对应 APK 安装（两者可共存）
2. 首次启动会请求麦克风权限（仅拾音时需要）
3. 建议先导入字体：顶栏 `▪字` → 选择字体文件 → 全局生效，下次启动自动加载

---

## 关于字体

仓库 Release 里附带两个字体（视发布情况）：

- **汇文明朝体 GBK**（约 44 MB，正文观感最佳）
- 若未附带，可用任意中文字体替代

导入方式：`▪字` → 文件选择器 → 选中 `.ttf` / `.otf` → 立即生效。

---

## 数据在哪里

| 内容 | 位置 |
|---|---|
| 正文、归档、注记 | 应用私有目录的 SQLite（`onlywrite.db`） |
| 录音 | `/storage/emulated/0/Music/OnlyWrite/*.m4a` |
| 导出的 TXT / JSON | 你自选的目录（通过侧栏「外送目录」授权一次） |

**应用私有目录卸载即清除。** 想长期保留，务必使用导出功能。

## 导出格式

**TXT** — 划线用 `⟦n⟧…⟦n⟧` 成对标记，`n` 是篇内序号：

```
2026-10-30 15:18:39 UTC+10:30

一地鸡毛
2026-10-30 15:14:07 UTC+10:30
　　怎么收拾，怎么⟦1⟧回忆⟦1⟧倾注心力也⟦3⟧收拾⟦3⟧不⟦4⟧难⟦4⟧能回头

──── 注记 ────
[1] 2026-10-30 15:52:11
    定位：回忆
    这里转得太快了
```

**`.chain.json`** — 完整修订链，可离线验签：

```json
{"docId":"...","archivedAt":...,"chainHead":"...","strikes":[...],"revisions":[...]}
```

验签方法：逐条重算 `sha256(docId|seq|parent|op|sha256(payload)|pos|s|e|ts)`，与记录里的 `hash` 比对，并检查 `parent` 串联与 `chainHead` 一致。

**`.notes.json`** — 注记数组，`[{s,e,anchor,body,ts}]`。

## 构建

```bash
gradle :app:testDebugUnitTest :app:assembleDebug :appdelta:assembleDebug
```

- 标准版输出：`app/build/outputs/apk/debug/`
- Delta 版输出：`appdelta/build/outputs/apk/debug/`

两个模块共用同一份源码（`app/src/main/java`），Delta 仅覆盖 `applicationId`、图标与提示实现。

版本号四段式：`主.次.本.末`，末位跟随 CI 构建号。

---

## 已知取舍

- 旧归档的划线信息无法补写（append-only，不改历史）
- 注记不可删除、不可编辑（与正文同一原则）
- 字体不内建，需手动导入一次
- 归档链快照不含注记（注记产生于归档之后，时间原点不同）
